# RootVault

RootVault is a work in progress, local-first password manager. All data is encrypted locally using AES-256 and never leaves your device. Features include a password generator, auto-lock, and the ability to securely import/export data.

View your app in AI Studio: https://ai.studio/apps/dcb00a1b-2e44-4934-99f0-cc48c102943e

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
